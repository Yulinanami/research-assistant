# 研数：科研数据建设与共享演示

使用 Vue 3、Element Plus、Vite。数据、附件和配置保存在当前浏览器的 IndexedDB 中。

## 运行与检查

```powershell
cd demo/web
npm.cmd install
npm.cmd run dev
npm.cmd test
npm.cmd run build
```

PowerShell 下使用 `npm.cmd` 可避免本机 `npm.ps1` 的执行策略限制。

## 主要入口

- 外部首页：未登录时独立展示，不使用工作空间侧栏；仅推荐公开且已发布的数据集，提供登录入口。
- 工作台：登录后默认页面，包含项目入口、跨项目任务与数据统计。工作空间侧栏不再列出首页。
- 数据加工：打开或创建项目后，按“需求规划 → 语料接入 → 数据预处理（解析、清洗）→ 数据标注 → 项目成果”建设数据。项目内提供自检、预览、导出与提交审核。
- 任务管理中心：右上角全局入口，汇总有权限项目的解析、清洗、生成与标注任务，支持状态、类型、项目、数据集筛选与分页。展示进度、创建时间、运行时间、模型及结果摘要，可查看日志、成果、修改任务名称、重试失败任务和删除已结束的任务记录。预设流程执行记录也在此跟踪，支持失败或中断后重试、查看成果及进入人工复核。删除记录保留资料与成果；旧记录缺失的耗时显示“未记录”。
- 流程配置：打开数据加工项目后，从当前项目栏进入配置抽屉，选择目标数据集、输入资料和自动执行步骤。启动后进入带项目与数据集筛选的任务管理中心。侧栏不再提供独立“加工任务”页面，旧 `#project-tasks` 地址兼容跳转到任务管理中心。
- 我的数据集：本人拥有的数据集。
- 数据目录：本人拥有及申请已获批的数据集。每个数据集聚合展示，版本历史默认折叠，授权不跨版本继承。
- 数据广场：可见的发布成果，支持申请指定版本。
- 质量审核：在数据治理与共享中跨项目审核已提交的数据集版本，支持质检参考、退回修改与通过审核；草稿和解析、清洗等中间成果不进入正式审核。
- 成果发布：在数据治理与共享中选择已通过审核的版本填写 Tag、标题与说明，发布后可在数据广场发现和申请使用。
- 设置：解析默认值、模型试用与评测、受众提示词、标签模板、清洗预设与导出默认值。

当前使用本地演示身份登录，登录状态保存在当前标签页的 sessionStorage，刷新后保持。未登录访问工作空间链接会返回外部首页；登录后访问空地址或旧首页链接会进入工作台。右上角身份菜单提供退出登录，退出不清除项目资料。正式账号验证与服务端会话尚未接入。

## 项目内加工

语料接入只负责导入、预览和资料管理，不提供解析与脱敏操作。数据预处理包含“文档解析 / 数据清洗”两个页签，解析支持 PDF、Word、Excel，文本与图片可直接清洗，已导入的结构化条目可直接标注。解析完成后自动更新可清洗输入，在本页继续试运行和批量清洗。原 `#cleaning` 地址兼容进入预处理的清洗页签。

预处理资料区只保留资料选择与数量，清洗通过页签切换，标注通过顶部流程进入。从旧解析版本或后续成果返回时按原始资料恢复选择；交接编号已失效时重新选择当前可用资料。未选择可解析文档时提示原因，并提供“选择可解析文档”入口；主动取消的勾选不会被资料刷新强行恢复。

清洗切换文本/图片类型时重新选择对应输入，上传与解析完成后同步更新勾选状态；支持接续选中的加工成果和导入条目。输入过期、未选择资料、任务运行中或无权限时，按钮旁展示原因，并在可重新选择时提供“选择可用资料”入口。解析与清洗记录集中进入任务管理中心，当前执行状态和结果仍可在预处理页查看。

本轮页面调整、任务字段与验证范围见 [预处理整合与任务管理中心](../../docs/平台调研/调研分析总结/10.预处理整合与任务管理中心.md)。

项目中可以建设多个数据集。资料、任务、流程实例和成果记录都带有项目关系；已有本地记录按原项目名称迁移，保留 ID、原始文件、版本及申请记录。

数据标注统一提供知识片段、知识图谱、问答生成、文本分类、图片整体分类、区域框选、图片描述、图片问答及问答人工复核，移除独立问答增强页。输入区统一为“选择输入资料”，仅按资料文件名称选择，不混入按处理类型与时间命名的历史成果；解析后的文档仍以原资料名称展示。模型生成和人工分类分别保存，不用预测覆盖人工结果。结果区仅展示当前方式最新一条任务和对应成果，完整历史在任务管理中心；新任务执行中或失败时不展示旧成果充当本次结果。

知识图谱参考 LightRAG 的“正文片段 → 实体与关系抽取 → 合并同名实体 → 人工校订”组织方式。可配置实体类型、候选名称、实体数量上限、片段大小及抽取提示词；支持图谱搜索、缩放、点击节点或连线查看来源，新增／修改／删除实体和关系，校订另存为独立成果并导出完整图谱 JSON。实体改名同步关系两端，删除实体同时删除关联关系。校订工作副本按身份、数据集与成果隔离保存；项目成果页也可继续校订。

当前图谱抽取使用本地演示规则，仅识别正文中的科研术语、引号内名称、英文名称或用户指定的候选名称，将同句共现作为候选关系，不推断因果。实体与关系保留片段、原资料、输入成果和记录位置。未连接真实 LightRAG／LLM 服务、图数据库、向量检索和图谱问答；导出为本项目的图谱 JSON，尚未验证直接导入 LightRAG。参考来源、难度与实现边界见 [知识图谱标注与结果区精简](../../docs/平台调研/调研分析总结/11.知识图谱标注与结果区精简.md)。

图片分类和框选可直接在本页选择文件，导入后立即继续操作；无图片时显示接入入口。框选支持正向、反向拖动及细小区域，保存原图快照与百分比坐标，成果页显示区域叠层。图片描述和图片问答的新成果包含原图，预览同时展示图文，完整图文导出请选择“原始结构”。

切换各建设方式会分别保留输入、提示词、任务和成果；空工作副本不会挡住新接入资料。自动标注先保存当前人工修订，再生成独立建议。重复增强不叠加受众前缀；知识片段按字素边界切片。旧的无图生成成果需重新生成。原九种方式的修复记录与实际浏览器验证范围见 [九种标注方式复现与修复](../../docs/平台调研/调研分析总结/9.数据标注九种方式问题复现清单.md)。

文件与粘贴条目统一校验 JSON/JSONL，支持原始条目、Alpaca 和 ShareGPT；多轮对话导出保留完整消息。Label Studio 的 `data.text/image` 可做基础输入映射，原始 `data`、`annotations` 和 `predictions` 分别保留，复杂控件与资源格式仍需适配。图片分类 JSON 重新导入后可按条续标并保留人工标签。结构化条目可以从预处理直接进入标注，不会被当成整份 JSON 正文清洗。

知识片段按上游保留记录分别切片，保留输入成果、原资料和记录位置。任务重试分配新编号；缺失或跨数据集输入不会回退示例内容生成成功成果。2026-10-22 的需求核对、问题清单、难度与三套布局草图见 [非治理模块复查](../../docs/平台调研/调研分析总结/7.非治理模块需求复查与问题清单.md)。

人工复核按项目成果或任务入口指定的版本打开。分类和框选草稿可以恢复续标，同一成果反复保存复用任务，切换成果分别关联任务。图片分类成果的编辑入口进入标签编辑，已提交版本修改后另存草稿。问答编辑回填当前生效答案，预览与导出使用同一份修订内容；任务管理中心支持筛选“标注中”和“已提交”。

分类检查模板内标签与单选/多选约束，切换模板或放弃未保存标注前需要确认；正常离开页面后保留按身份、数据集与方式隔离的工作副本，刷新前仍需保存草稿。模型建议保留人工标签和评分，人工复核另存结果。图片区域成果包含图片内容和百分比坐标。任务冻结启动时的输入快照；资料修订后不会自动复用旧解析。项目导出可选择全部未过滤记录或仅人工确认可用的记录；训练结构默认使用后者。完整问题与边界见 [数据加工与标注专项复查](../../docs/平台调研/调研分析总结/8.数据加工与数据标注专项复查.md)。

数据字典中作用范围为“数据集元数据”的字段会出现在数据集规划表单，保存到元数据中并在全局详情展示。数据集检索标签与样本标注标签分开维护。

项目内“流程配置”可预设自动执行文本清洗、知识片段和问答生成；文档输入先解析。流程保存配置快照，成功后衔接下一步，失败停止，生成问答后等待人工复核。仅生成中间成果的流程标记为已完成。页面刷新会中断本地任务，重开后可在任务管理中心重试当前步骤。

项目成果提供后续加工入口，并支持原始结构、Alpaca、ShareGPT 的 JSON/JSONL 导出；问答结构导出会校验问题和答案。提交审核保持在项目成果页，可点击查看审核进度进入治理；标注完成后提交则直接进入质量审核。编辑待审核、已通过或已发布内容会创建新草稿，保留原版本。正式审核与发布统一在治理模块完成，对外下载仍需指定版本的使用授权。旧的 #review 地址兼容跳转到 #audit。

## 实现边界

本地可执行：文本规则清洗、字符或分隔符切片、文件保存、人工分类与框选、版本快照、模板配置和导出映射。

模拟能力：PDF/Word/Excel 解析、模型生成与评测、图片质量及尺寸信息、MySQL 导入、数据服务接口。尚未接入真实 Data-Juicer 执行器；清洗预设是本地规则演示，完整 YAML 配置及外部算子执行属于后续引擎接入。权限为前端演示身份，正式部署还需服务端身份与授权检查。

测试覆盖版本发布与授权、规则清洗、来源保留、旧数据迁移、目录聚合、导出结构、分类输入与跨数据集隔离，以及生效答案编辑、复核版本定位、标注任务关联和分类草稿匹配。浏览器完整流程检查使用独立配置目录，不影响用户实际浏览器数据。
