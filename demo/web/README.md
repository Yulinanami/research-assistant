# 研数：科研数据建设与共享演示

使用 Vue 3、Element Plus、Vite。数据、附件和配置保存在当前浏览器的 IndexedDB 中。

## 运行与检查

```powershell
cd demo/web
npm.cmd install
npm.cmd run dev
npm.cmd test
npm.cmd run build
```

PowerShell 下使用 `npm.cmd` 可避免本机 `npm.ps1` 的执行策略限制。

## 主要入口

- 外部首页：未登录时独立展示，不使用工作空间侧栏；仅推荐公开且已发布的数据集，提供登录入口。
- 工作台：登录后默认页面，包含项目入口、跨项目任务与数据统计。工作空间侧栏不再列出首页。
- 数据加工：打开或创建项目后，按“需求规划 → 语料接入 → 数据预处理（解析、清洗）→ 数据标注 → 项目成果”建设数据。项目内提供自检、预览、导出与提交审核。
- 新建项目：分为“基本信息与可见范围”和“数据字典”。支持课题组内部可见、全员可见、个人可见；创建后可从项目卡片的“项目设置”维护。全员指平台内有查看权限的用户；可见范围与角色权限共同控制项目、数据集、资料及任务访问。
- 任务管理中心：右上角全局入口，汇总有权限项目的解析、清洗、生成与标注任务，支持状态、类型、项目、数据集筛选与分页。展示进度、创建时间、运行时间、模型及结果摘要，可查看日志、成果、修改任务名称、重试失败任务和删除已结束的任务记录。预设流程执行记录也在此跟踪，支持失败或中断后重试、查看成果及进入人工复核。删除记录保留资料与成果；旧记录缺失的耗时显示“未记录”。
- 流程配置：打开数据加工项目后，从当前项目栏进入配置抽屉，选择目标数据集、输入资料和自动执行步骤。启动后进入带项目与数据集筛选的任务管理中心。侧栏不再提供独立“加工任务”页面，旧 `#project-tasks` 地址兼容跳转到任务管理中心。
- 我的数据集：本人拥有的数据集。
- 数据目录：本人拥有及申请已获批的数据集。每个数据集聚合展示，版本历史默认折叠，授权不跨版本继承。
- 数据广场：可见的发布成果，支持申请指定版本。
- 质量审核：在数据治理与共享中跨项目审核已提交的数据集版本，支持质检参考、退回修改与通过审核；草稿和解析、清洗等中间成果不进入正式审核。
- 成果发布：在数据治理与共享中选择已通过审核的版本填写 Tag、标题与说明，发布后可在数据广场发现和申请使用。
- 设置：解析默认值、模型试用与评测、受众提示词、标签模板、清洗预设与导出默认值。

当前使用本地演示身份登录，登录状态保存在当前标签页的 sessionStorage，刷新后保持。未登录访问工作空间链接会返回外部首页；登录后访问空地址或旧首页链接会进入工作台。右上角身份菜单提供退出登录，退出不清除项目资料。正式账号验证与服务端会话尚未接入。

## 项目内加工

语料接入只负责导入、预览和资料管理，不提供手动解析与脱敏操作。文档解析是预处理的默认后台环节：PDF、Word、Excel 接入后自动创建解析任务，切换页面不影响执行；进度、结果与失败重试统一进入任务管理中心。预处理页面提供“数据清洗、知识片段生成、文本问答对提取、SFT 问答对增强”四个单选卡片，点击整张卡片立即选中并展示对应内容；不再提供文档解析页签。文本与图片可直接清洗，解析完成后自动更新可清洗输入。原 `#cleaning` 地址兼容进入预处理。

语料接入的状态筛选与列表标签统一为“已接入、待自动解析、解析中、已解析、解析失败、已处理”，兼容旧筛选值；解析状态按当前修订的可用成果与执行状态展示，失败使用错误标签。清洗规则按卡片版块勾选，展示编号和执行顺序，保留预设、调序、试运行和批量执行。取消资料勾选不影响后台解析，主动取消的勾选不会被资料刷新强行恢复。清洗页的返回入口指向语料接入，未就绪资料的解析记录与重试入口指向任务管理中心。

预处理版块只保留顶部卡片入口，移除重复页签、资料状态标签、清洗预设工具栏和说明小字，不展示执行顺序与数量提示；清洗仍支持勾选、按编号调序、试运行和批量执行，保留必要的不可执行原因与模拟标识。文本清洗移除 think 标签处理选项，默认预设、已有本地预设和设置中的选项同步移除。

知识片段生成的右侧配置随切片类型切换：固定大小设置字符数，分隔符设置切分符号，按段落设置每块段落数；三种参数分别保留，任务只使用当前类型的参数，保留标题、来源与上游记录位置，可将候选片段另存为知识片段数据集，或继续提取文本问答。问答提取与 SFT 增强先保存中间候选，通过本环节的人工复核修改、质量标记和提交，形成项目内的数据集草稿，不自动跳转治理平台；已有复核成果保留关联，可继续编辑。SFT 增强只使用已有问答数据集或导入的问答条目，提示词、受众与模型随任务保存。各版块最新结果与完整任务历史分开展示。实现范围与难度见 [预处理版块与问答建设整合](../../docs/平台调研/调研分析总结/14.预处理版块与问答建设整合.md)。

自动解析使用接入时的默认解析配置快照，设置中的调整用于后续新任务和失败重试。同一资料修订正在解析时复用任务，已有有效结果时复用成果；项目预设流程可以接续正在执行的自动解析，避免重复创建任务。旧资料中尚未解析的文档在有编辑权限的成员登录后补充创建任务，失败和刷新中断的任务保留记录，等待手动重试。当前解析仍为本地模拟，未接入真实文档解析服务。本次调整按用户要求未运行测试、构建或浏览器回归。

清洗切换文本/图片类型时重新选择对应输入，上传与解析完成后同步更新勾选状态；支持接续选中的加工成果和导入条目。输入过期、未选择资料、任务运行中或无权限时，按钮旁展示原因，并在可重新选择时提供“选择可用资料”入口。解析与清洗记录集中进入任务管理中心，预处理页保留本次清洗的执行状态和结果。

本轮页面调整、任务字段与验证范围见 [预处理整合与任务管理中心](../../docs/平台调研/调研分析总结/10.预处理整合与任务管理中心.md)。

项目中可以建设多个数据集。资料、任务、流程实例和成果记录都带有项目关系；已有本地记录按原项目名称迁移，保留 ID、原始文件、版本及申请记录。

数据标注参考 Label Studio 按数据类型组织模板，提供文本、图像、问答与图文四类；文本支持分类，图像支持分类、框选与描述，问答支持人工复核，图文支持图片问答。知识图谱作为文本类型下的标注流程，不再提供独立知识库页面；知识片段、文本问答生成和 SFT 问答增强统一移至预处理，不再作为标注页的重复入口。输入区统一为“选择输入资料”，按资料文件名称选择；预处理的“选择输入资料”仅提供接入资料，按原文件名使用当前解析内容，不列出清洗和知识片段历史成果；问答增强单独选择已有问答语料版本，不使用按时间命名的任务充当输入。模型生成和人工分类分别保存，不用预测覆盖人工结果。结果区仅展示当前方式最新一条任务和对应成果，完整历史在任务管理中心；新任务执行中或失败时不展示旧成果充当本次结果。

数据标注中的知识图谱流程按“原始资料 → 知识编译 → 实体关系抽取与来源校订”组织。接入的有效正文和优质问答自动创建知识编译任务，形成带摘要、分节摘录、主题与来源的页面，再自动聚合成知识图谱。同一资料修订复用任务与成果，变化后重建，过期结果不替换当前内容；关闭或刷新造成的任务中断可在任务管理中心重试。

知识图谱流程内保留图谱及原始资料和知识页面目录树，可切换查看原文、知识页面、图谱及来源证据。当前知识编译为本地摘录演示，关系抽取为词项识别与同句共现候选关系，尚未调用真实大模型、LightRAG 或后端持久队列；页面保留演示标识。按用户要求未运行应用回归。Label Studio 本地模板访问记录、设计映射、自动流程边界与开发难度见 [数据类型标注与三层知识库建设](../../docs/平台调研/调研分析总结/15.数据类型标注与三层知识库建设.md)。

图片分类和框选可直接在本页选择文件，导入后立即继续操作；无图片时显示接入入口。框选支持正向、反向拖动及细小区域，保存原图快照与百分比坐标，成果页显示区域叠层。图片描述和图片问答的新成果包含原图，预览同时展示图文，完整图文导出请选择“原始结构”。

切换各建设方式会分别保留输入、提示词、任务和成果；空工作副本不会挡住新接入资料。自动标注先保存当前人工修订，再生成独立建议。重复增强不叠加受众前缀；知识片段按字素边界切片。旧的无图生成成果需重新生成。原九种方式的修复记录与实际浏览器验证范围见 [九种标注方式复现与修复](../../docs/平台调研/调研分析总结/9.数据标注九种方式问题复现清单.md)。

文件与粘贴条目统一校验 JSON/JSONL，支持原始条目、Alpaca 和 ShareGPT；多轮对话导出保留完整消息。Label Studio 的 `data.text/image` 可做基础输入映射，原始 `data`、`annotations` 和 `predictions` 分别保留，复杂控件与资源格式仍需适配。图片分类 JSON 重新导入后可按条续标并保留人工标签。结构化条目可以从预处理直接进入标注，不会被当成整份 JSON 正文清洗。

知识片段按上游保留记录分别切片，保留输入成果、原资料和记录位置。任务重试分配新编号；缺失或跨数据集输入不会回退示例内容生成成功成果。2026-10-22 的需求核对、问题清单、难度与三套布局草图见 [非治理模块复查](../../docs/平台调研/调研分析总结/7.非治理模块需求复查与问题清单.md)。

人工复核按项目成果或任务入口指定的版本打开。分类和框选草稿可以恢复续标，同一成果反复保存复用任务，切换成果分别关联任务。图片分类成果的编辑入口进入标签编辑，已提交版本修改后另存草稿。问答编辑回填当前生效答案，预览与导出使用同一份修订内容；任务管理中心支持筛选“标注中”和“已提交”。

分类检查模板内标签与单选/多选约束，切换模板或放弃未保存标注前需要确认；正常离开页面后保留按身份、数据集与方式隔离的工作副本，刷新前仍需保存草稿。模型建议保留人工标签和评分，人工复核另存结果。图片区域成果包含图片内容和百分比坐标。任务冻结启动时的输入快照；资料修订后不会自动复用旧解析。项目导出可选择全部未过滤记录或仅人工确认可用的记录；训练结构默认使用后者。完整问题与边界见 [数据加工与标注专项复查](../../docs/平台调研/调研分析总结/8.数据加工与数据标注专项复查.md)。

新项目维护独立业务数据字典，可新增字段或复制公共字典字段，配置名称、编码、类型、必填、枚举、单位和说明。文本、数值、枚举、日期、布尔字段会生成对应的数据集规划控件，填写值保存到数据集元数据中，详情优先使用项目字典名称。数据集编号为系统自动生成字段，不能被自定义字段占用。旧项目未保存项目字典前继续使用公共元数据字段；原已删除的作物类型不自动回到新建数据集表单。数据集检索标签与样本标注标签分开维护。

已注册并登录本地 Label Studio 参考其项目字段配置界面，将业务字典改为“左侧配置 / 右侧实时表单预览”。支持可视化与 JSON 编辑、科研采样／文献／通用业务字段模板、公共字段复制、按行批量添加、枚举选项预览、配置导出及示例填写校验。保存项目时会应用当前 JSON 编辑，无效配置会阻止保存；取消弹窗后再打开会重新加载项目配置。实际来源与差异见 [Label Studio 字段配置体验与字典调整](../../docs/平台调研/调研分析总结/13.LabelStudio字段配置体验与字典调整.md)。

可见范围使用当前浏览器演示身份与课题组成员记录判断。初始“科研课题组”包含管理员、加工人员和审核人员；数据使用者不在该组。旧项目保持全员可见以保留既有访问行为。真实账号、课题组组织关系及服务端授权仍需后续接入。设计来源与难度见 [项目可见范围与业务数据字典](../../docs/平台调研/调研分析总结/12.项目可见范围与业务数据字典.md)。

项目内“流程配置”可预设自动执行文本清洗、知识片段和问答生成；文档输入先解析。流程保存配置快照，成功后衔接下一步，失败停止，生成问答后等待人工复核。仅生成中间成果的流程标记为已完成。页面刷新会中断本地任务，重开后可在任务管理中心重试当前步骤。

项目成果提供后续加工入口，并支持原始结构、Alpaca、ShareGPT 的 JSON/JSONL 导出；问答结构导出会校验问题和答案。提交审核保持在项目成果页，可点击查看审核进度进入治理；标注完成后提交则直接进入质量审核。编辑待审核、已通过或已发布内容会创建新草稿，保留原版本。正式审核与发布统一在治理模块完成，对外下载仍需指定版本的使用授权。旧的 #review 地址兼容跳转到 #audit。

## 实现边界

本地可执行：文本规则清洗、字符或分隔符切片、文件保存、人工分类与框选、版本快照、模板配置和导出映射。

模拟能力：PDF/Word/Excel 解析、模型生成与评测、图片质量及尺寸信息、MySQL 导入、数据服务接口。尚未接入真实 Data-Juicer 执行器；清洗预设是本地规则演示，完整 YAML 配置及外部算子执行属于后续引擎接入。权限为前端演示身份，正式部署还需服务端身份与授权检查。

测试覆盖版本发布与授权、规则清洗、来源保留、旧数据迁移、目录聚合、导出结构、分类输入与跨数据集隔离，以及生效答案编辑、复核版本定位、标注任务关联和分类草稿匹配。浏览器完整流程检查使用独立配置目录，不影响用户实际浏览器数据。

数据标注新增成果审核，支持提交、通过、退回、意见与审核历史；内容修改后须重新提交。分类、框选、问答提交后在标注页内审核，通过后再按需进入正式治理流程。右上角后台配置集中维护解析、QA、知识图谱与图文提示词，任务创建时保存实际配置快照。实现范围与难度见 [知识图谱标注流程、成果审核与后台配置](../../docs/平台调研/调研分析总结/16.知识图谱标注流程与成果审核及后台配置.md)。
