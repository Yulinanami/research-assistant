## 3.1.2 功能清单与功能说明

定位：通过可配置界面，组织人员对文本、图片等数据进行标注，并导出结果。本次以社区版为调研对象。

| 序号 | 功能模块 | 功能说明 | 对应本项目功能 |
| --- | --- | --- | --- |
| 1 | 项目和任务配置 | 创建项目，导入资料，通过模板或 XML 设置界面 | 标注任务创建、待标注数据上传 |
| 2 | 文本分类 | 为整段文字选择类别 | 文本分类与数据筛选 |
| 3 | 文本实体标注 | 选择文字范围，标记时间、深度、指标等实体 | 文本信息人工标注 |
| 4 | 图片区域标注 | 对图片中的区域框选并选择标签 | 图像标注 |
| 5 | 问答与结果评价 | 配置问题、回答、评分或修改输入框 | 问答对标注、人工评价 |
| 6 | 模型辅助与导出 | 导入预标注或连接外部模型；按任务类型导出结果 | 模型辅助标注、标注成果交付 |

模型辅助需要额外模型服务。人工标注、自动预测和正式审核是不同环节，不能将提交结果直接视为已审核发布。

## 3.1.3 优势功能分析

### 优势功能1：按任务配置标注界面

- **功能描述：** 用模板或 XML 组合资料展示、分类、框选和文本输入控件。
- **技术实现：** 输入字段与控件通过名称关联，界面将操作保存为结构化标注。
- **差异化价值：** 同一工具可以承接不同标注任务，无需为每类任务单独开发页面。
- **可借鉴方向：** 提供常用农业任务模板，同时允许调整标签和说明。

### 优势功能2：标注结果与原始任务关联

- **功能描述：** 保存任务资料、人工标注及可选的模型预测。
- **技术实现：** 任务、标注、预测和草稿分别保存，结果引用相应字段和区域。
- **差异化价值：** 可区分原始资料、模型建议和人工结果，便于后续处理。
- **可借鉴方向：** 保留原始输入和人工修订，不用模型预测覆盖最终标注。

### 实际体验

已在本地配置科研语料分类，标签为研究背景、试验方法、研究结果和无效内容，并完成 JSON 导出。后续完成实体标注，标签包括采样时间、采样深度、土壤含水量，提供了第二份 JSON 结果。

已有记录核对了分类和实体标注成果。图片框选已提供“图、表、公式”的配置与操作指导，尚无该任务的导出结果作为完成证据；不计入已验证效果。

2026-10-22 按用户授权注册本地参考账号，登录查看项目设置的 Labeling Interface 与数据管理页。实际界面提供字段绑定、Visual/Code 切换、按行添加标签、模板选择和右侧预览；实体项目的数据列为 `text`、`sample_id`。本项目据此调整项目业务字典的编辑与预览交互，详情与截图见 [字段配置体验与字典调整](../调研分析总结/13.LabelStudio字段配置体验与字典调整.md)。本次只读查看既有项目，未修改其任务或标注。

## 3.1.4 技术架构概述

- **整体架构：** Web 应用，浏览器展示任务，后端保存项目、资料和标注结果。
- **核心依赖：** Django/DRF、React；数据库可使用 SQLite 或 PostgreSQL。
- **模型支持：** 通过外部 ML Backend 或预标注结果接入模型，默认不自带业务模型。
- **扩展机制：** XML 配置、模板、REST API、Python SDK 与 Webhook。[C9]、[C10]

## 3.1.6 与本项目的关系

- **可直接集成的能力：** 优先验证文本分类、实体标注和图片框选，作为人工标注工作台候选。
- **可借鉴的设计理念：** 一类任务一套清晰配置，原始资料、预测和人工结果分别保存。
- **本项目相对优势：** 规划覆盖农业规则、正式审核、分级权限及数据版本；社区版不能完整覆盖这些流程。
- **本项目相对短板：** 标注控件和结果结构仍需落地，可借鉴现有成熟交互，减少重复开发。

需要区域框选时优先考虑 Label Studio；针对问答评分和修改，也可使用 Argilla，不要求同一任务重复经过两套标注工具。

## 3.1.7 调研结论

| 评估项 | 结论 |
| --- | --- |
| 推荐集成/借鉴程度 | 高：人工标注界面与任务配置 |
| 技术成熟度 | 分类和实体标注已体验；图片框选及模型辅助待结果验证 |
| 社区活跃度 | 沿用基本信息中的原调研记录 |
| 一句话总结 | 适合对准备好的文本和图片做人工标注，自动生成和业务审核需另行组织 |

使用门槛主要在字段与 XML 配置的对应关系。原生 JSON 保存标注结构，图片框坐标等字段需按目标格式转换；文件导出不等于直接得到训练数据。社区版与商业版的协作、审核和权限能力应分别确认。[C5]、[C40]

实际体验依据：2026-10-15 的界面截图与两份标注导出记录；未验证多人协作、模型辅助或批量性能。
