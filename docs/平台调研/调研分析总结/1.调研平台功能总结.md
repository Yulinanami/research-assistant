 6 个平台覆盖了文档解析、数据清洗、问答生产、人工标注和质量评价几个环节，适合作为不同组件组合使用。

## 1. 功能与用途总览

| 平台 | 核心功能 | 主要用途 | 在本项目中的角色 |
|---|---|---|---|
| Easy Dataset | 文档导入、文本分块、问题与答案生成、人工编辑、数据导出 | 将专业资料加工成大模型问答训练数据 | 问答数据集生产工具 |
| Data-Juicer | 文本规范化、噪声清理、脱敏、质量过滤、精确／近重复去重、分块、模型加工、数据分析 | 按配置批量加工数据，提高语料质量 | 后台数据加工引擎 |
| MinerU | PDF 版面分析、OCR、正文与阅读顺序恢复、表格和公式识别、图片提取、结构化导出 | 把论文、扫描件等文档转换为可加工内容 | 科研文献解析组件 |
| Docling | 多格式文档解析、版面与表格识别、OCR、统一文档结构、来源位置保留、知识分块 | 将不同格式资料转换为统一结构，服务检索和 AI 应用 | 文档解析与知识准备组件 |
| Label Studio | 文本分类、实体圈选、图片框选等多类型标注；预标注修订、模型辅助、结果导出 | 组织人工标注，生成训练与评价标签 | 通用人工标注工作台 |
| Argilla | 分类、实体标注、质量评分、答案修订、回答排序、模型建议及多人反馈 | 收集专家判断，筛选和改进 AI 数据 | 问答质量评价与反馈工作台 |

## 2. 用同一份科研资料理解它们

假设我们拿到一篇农业论文：

| 环节 | 可以使用的平台 | 做什么 |
|---|---|---|
| 读出文档 | MinerU／Docling | 提取正文、图片、表格、公式及结构信息 |
| 整理语料 | Data-Juicer | 清理标签、脱敏、去重、过滤和切分 |
| 生成问答 | Easy Dataset | 根据知识片段生成问题与答案 |
| 添加人工标签 | Label Studio | 标记资料类别、圈出时间与试验参数、框选图片区域 |
| 评价问答质量 | Argilla | 评分、判断是否可用、填写修订或比较回答优劣 |

这是候选组合方式，目前尚未完成六个平台之间的实际集成。

## 3. 容易混淆的地方

### MinerU 与 Docling

两者都负责文档解析。后续应使用同一批资料，对比正文、表格、公式、来源定位、耗时和部署成本，再选择或组合。

### Label Studio 与 Argilla

两者都能人工标注，能力有重叠：

- Label Studio 更适合重点评估多种资料、标注方式的统一工作台。
- Argilla 更适合重点评估围绕模型回答收集评分、修订和偏好反馈。

### Easy Dataset 与 Data-Juicer

- Easy Dataset 更贴近“文档到问答”的可视化生产流程。
- Data-Juicer 更贴近配置化、可复用的批量加工，适合作为后台引擎。

## 5. 结论

> 六个平台可以为本项目提供不同环节的能力：MinerU、Docling 负责解析，Data-Juicer 负责清洗加工，Easy Dataset 负责问答生产，Label Studio 和 Argilla 负责人工标注与质量反馈。建议按组件复用和交互设计借鉴来评估，结合真实科研资料验证效果。数据需求规划、审批、权限、成果发布及资产版本管理，仍需由本项目统一组织建设。
