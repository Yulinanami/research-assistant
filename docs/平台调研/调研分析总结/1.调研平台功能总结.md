 6 个平台覆盖了文档解析、数据清洗、问答生产、人工标注和质量评价几个环节，可以作为不同组件组合使用。

## 1. 功能与用途总览

| 平台 | 核心功能 | 主要用途 | 在本项目中的角色 |
|---|---|---|---|
| Easy Dataset | 文档导入、文本分块、问题与答案生成 | 将专业资料加工成大模型问答训练数据 | 问答数据集生产工具 |
| Data-Juicer | 文本规范化、噪声清理、脱敏、质量过滤、去重、分块、模型加工、数据分析 | 按配置加工数据，提高语料质量 | 后台数据加工引擎 |
| MinerU | PDF 版面分析、OCR、表格和公式识别、图片提取 | 把论文、扫描件等文档转换为可加工内容 | 科研文献解析组件 |
| Docling | 多格式文档解析、版面与表格识别、OCR、来源位置保留、文档分块 | 对于同一文献的不同格式可转换为统一结构，服务检索和 AI 应用 | 文档解析与分块工具 |
| Label Studio | 文本分类、实体圈选、图片框选等多类型标注 | 人工标注，生成训练与评价标签 | 通用标注工作台 |
| Argilla | 分类、实体标注、质量评分、答案修改 | 收集专家判断，筛选和改进 AI 数据 | 问答质量评价与反馈工作台 |

## 2. 数据处理举例

假设我们拿到一篇论文：

| 环节 | 可以使用的平台 | 做什么 |
|---|---|---|
| 读出文档 | MinerU／Docling | 提取正文、图片、表格、公式及结构信息 |
| 整理语料 | Data-Juicer | 清理标签、脱敏、去重、过滤和切分 |
| 生成问答 | Easy Dataset | 根据知识片段生成问题与答案 |
| 添加人工标签 | Label Studio | 标记资料类别、圈出时间与试验参数、框选图片区域 |
| 评价问答质量 | Argilla | 评分、判断是否可用、填写修改后的答案或比较回答优劣 |

## 3. 相似的功能

### MinerU 与 Docling

两者都负责文档解析。个人体验下来 MinerU 的解析精度更好。 

### Label Studio 与 Argilla

两者都能人工标注：

- Label Studio 更适合对文本、图片等资料进行不同类型的人工标注。
- Argilla 更适合收集模型回答的评分和修改意见。

### Easy Dataset 与 Data-Juicer

两者都能进行数据清洗：

- Easy Dataset 将文档导入、文本清洗和问答生成放在同一工作台中。
- Data-Juicer 可以配置清洗规则和执行顺序，并重复用于多批数据。

## 5. 结论

六个平台可以为本项目提供不同环节的能力：

MinerU、Docling 负责解析文献，Data-Juicer 负责数据清洗加工，Easy Dataset 负责问答生产，Label Studio 和 Argilla 负责人工标注与质量反馈。
