# 预处理整合与任务管理中心

调整日期：2026-10-22。按本轮用户要求，将解析从语料接入移入预处理，清洗并入预处理。

## 1. 页面与流程

主流程改为：需求规划 → 语料接入 → 数据预处理 → 数据标注 → 项目成果。

- 语料接入：上传、条目导入、预览、编辑与删除资料，可将指定资料交接给预处理；移除解析、脱敏及解析任务记录。
- 数据预处理：“文档解析 / 数据清洗”两个页签。PDF、Word、Excel 在此选择参数并解析，完成后自动接续正文进行清洗；文本、图片可直接清洗。
- 任务管理中心：右上角全局入口，执行中任务显示数量。解析、清洗页可直接打开对应类型与数据集的任务记录。
- 原清洗步骤从流程导航移除；旧的 `#cleaning` 地址进入预处理的清洗页签。
- 侧栏移除“加工任务”页面，旧 `#project-tasks` 地址跳转到任务管理中心。项目内当前项目栏提供“流程配置”抽屉，选择输入与步骤后启动流程；启动后进入带项目、数据集筛选的任务中心。

## 2. 任务管理

| 功能 | 行为 | 难度 |
| --- | --- | --- |
| 记录汇总 | 汇总解析、清洗、切片、问答生成与标注，按项目权限过滤 | 中 |
| 筛选与分页 | 状态、类型、项目、数据集、任务搜索、每页条数；刷新保留筛选 | 低 |
| 过程展示 | 进度、输入数量、创建时间、运行耗时、使用模型、结果摘要 | 中 |
| 详情与成果 | 查看日志和配置快照；成果跳转到所属项目及数据集 | 低 |
| 失败重试 | 分配新任务编号，清除旧成果、完成时间与进度统计 | 中 |
| 记录删除 | 删除任务记录，保留原始资料和成果；执行中的任务与流程不允许删除 | 中 |
| 历史兼容 | 不为旧记录补造耗时；模型名称随新任务保存，后续改名不影响历史展示 | 低 |
| 入口归并 | 移除独立加工任务页，工作台、成果页与旧链接统一使用任务管理中心 | 低 |
| 流程配置迁移 | 在项目内选择目标数据集、输入与步骤，启动时冻结配置，检查输入和编辑权限 | 中 |
| 流程跟踪 | 任务中心展示流程步骤、状态及失败原因，支持重试、成果与人工复核入口 | 中 |

以上页面与本地记录能力已实现。后台任务队列、真正的文档解析引擎与跨设备实时同步尚未接入。

## 3. 验证与边界

组件运行测试覆盖：预处理启动解析、重复点击防重、配置快照、解析结果自动选中并清洗、旧地址兼容、语料接入不能启动处理、任务筛选分页与权限、删除记录保留成果、耗时与模型快照及重试字段重置。

独立 Edge 浏览器检查覆盖：语料页无解析/清洗入口；预处理内实际点击解析、小样本试运行、批量清洗；右上角任务中心与执行数量；截图对应字段、类型筛选、刷新、详情和成果跳转；旧清洗链接兼容。使用独立配置与临时样本，不改动用户浏览器的数据。

另外在浏览器制造一次失败任务，实际点击重试并等待成功，再确认删除原失败记录，验证任务数量减少而成果与资料保留。补充真实组件渲染检查，确认切回解析页签后整个清洗区隐藏，并消除对多根组件使用显示指令的警告。自动化全套 78 项通过，生产构建和差异检查通过；构建仍有既有的产物体积提示。

耗时记录浏览器本地执行时间，页面刷新仍会中断模拟任务。PDF/Word/Excel 解析和模型相关结果仍为模拟；文本规则清洗在本地执行。任务中心不会把本地规则任务显示为使用了模型。

后续入口归并的组件运行验证覆盖：流程配置的输入、步骤与权限校验；启动时保留步骤和参数快照；任务中心跟踪流程失败、重试和成果；问答流程进入人工复核；流程按项目、数据集与状态筛选；工作台任务跳转与旧加工任务地址兼容。

入口归并另以独立 Edge 浏览器实际点击验证：侧栏已移除旧页面；项目内打开流程配置，选择 PDF 与知识片段步骤，启动后关闭抽屉并进入任务中心；解析和切片完成后查看正确成果；成果页任务记录及旧地址进入任务中心；无编辑权限时显示原因并禁用启动。上述操作通过，未出现 Vue 警告；全套自动化 86 项通过，生产构建通过。
