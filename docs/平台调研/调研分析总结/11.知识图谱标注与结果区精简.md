# 知识图谱标注与结果区精简

调整日期：2026-10-22。知识图谱作为数据标注的一种建设方式；标注结果区仅保留当前方式最新一条任务与对应成果，历史记录进入任务管理中心。

## 1. LightRAG 参考依据

官方结构将实体表示为名称、类型和描述，将关系表示为两端实体、关键词和描述；图谱接口另以节点与边表达连接。[官方类型定义](https://github.com/HKUDS/LightRAG/blob/main/lightrag/types.py)

官方自定义图谱示例使用 `chunks / entities / relationships`，以 `source_id / file_path` 关联正文来源；实体编辑、关系编辑及删除能力用于维护图谱。[官方核心编程文档](https://github.com/HKUDS/LightRAG/blob/main/docs/ProgramingWithCore.md#insert-custom-kg)

本项目据此组织“正文片段 → 候选实体与关系 → 同名去重 → 人工校订 → 项目成果”，不将知识检索与问答作为本次标注流程的一部分。

## 2. 功能与难度

| 需求点 | 本轮行为 | 难度 |
| --- | --- | --- |
| 标注入口 | 增加知识图谱，按建设方式保存输入与抽取配置 | 低 |
| 抽取配置 | 实体类型、候选名称、实体上限、片段大小、模型与提示词快照 | 中 |
| 本地抽取演示 | 仅从实际正文匹配名称；合并同名实体，按同句共现生成候选关系 | 中 |
| 来源追溯 | 实体与关系关联来源片段；片段保存原资料、输入成果及记录位置 | 中 |
| 图谱预览 | 节点、连线、搜索、缩放；点击实体或连线查看来源 | 中 |
| 人工校订 | 新增／编辑／删除实体和关系；改名同步关系，删除实体清除关联关系 | 中 |
| 成果保存 | 校订另存新成果，保留原图谱；工作副本按身份与成果隔离 | 中 |
| 图谱导出 | 导出本项目图谱 JSON，完整保留实体、关系及来源片段 | 低 |
| 任务归集 | 抽取和校订进入任务中心，展示实体／关系数量与校订状态 | 低 |
| 结果区精简 | 仅展示最新任务与对应成果；新任务执行中或失败不冒用旧结果 | 低 |
| 真实 LightRAG 服务 | 后续接入服务端抽取、图存储、模型调用及增量构建 | 高，后续开发 |

## 3. 实现边界

本轮为浏览器演示。候选名称留空时识别科研术语、引号内名称及英文名称；填写后仅匹配用户指定且正文中实际存在的名称。关系“同句共现”只表示共同出现，须经人工校订后确定实际语义，不表示因果或模型推理。

没有命中实体时提示填写候选名称后重试，不补造示例实体。达到实体上限时提示部分候选未纳入。过滤记录、图片、缺失或跨数据集输入不能用于正文图谱抽取。

模型与提示词随任务保存，当前不调用真实模型。未接入 LightRAG 服务、图数据库、向量检索和图谱问答。JSON 保留本项目扩展的多来源字段，尚未做真实 LightRAG 导入联调。

## 4. 验证范围

自动化覆盖正文匹配、同句证据、同名去重、多记录来源、过滤输入、实体上限与类型、改名和删除一致性、悬空关系与重复关系拦截、导出快照、任务输入和配置冻结、校订草稿恢复、新成果保留原版本、权限控制，以及结果区只取最新任务且不展示旧结果。

独立 Edge 浏览器实际验证：十种标注入口可用；从科研正文生成 11 个实体与 8 条候选关系；点击节点查看来源；实体改名同步关系端点；校订形成新版本并保留原图谱；实际下载 JSON 中包含实体、关系和完整来源片段；任务中心正确汇总校订状态，项目成果页可显示图谱；连续两次问答生成后页面仅显示一条任务与一张成果卡，历史记录完整保留。页面切换未出现 Vue 警告。

另外修复工作区重置后，旧标注页离开时尝试保存已清除工作副本导致的异常，并补充回归验证。
