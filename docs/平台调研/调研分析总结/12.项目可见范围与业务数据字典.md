# 项目可见范围与业务数据字典

日期：2026-10-22。按用户确认，数据字典指项目业务字段配置，用于新建数据集，不是标注标签模板。

## 1. 参考来源

Label Studio 官方项目创建界面将项目信息、数据导入、标注配置分组；本项目借鉴其分组方式，采用“基本信息与可见范围 / 数据字典”两个页签。[创建项目文档](https://labelstud.io/guide/setup_project.html)

Label Studio 支持在项目设置中继续维护项目名称、说明和标注配置。本项目相应提供“项目设置”入口，并将数据集业务字段放到项目内维护。[项目设置文档](https://labelstud.io/guide/project_settings)

三种可见范围是本项目业务需求，不声称为 Label Studio 社区版原生选项。首次访问本地 `http://127.0.0.1:8080/` 时返回登录页；后续已按用户授权注册参考账号，登录查看项目字段与标签配置，并调整业务字典界面，详见 [实际体验记录](13.LabelStudio字段配置体验与字典调整.md)。

## 2. 页面与规则

| 功能 | 实现行为 | 难度 |
| --- | --- | --- |
| 新建项目 | 项目名称、建设目标，可见范围与字典分组配置 | 低 |
| 课题组内部可见 | 创建者与所选课题组成员可查看，角色权限继续限制可执行操作 | 中 |
| 全员可见 | 平台内有查看权限的用户可见，不等于向外部首页公开 | 中 |
| 个人可见 | 仅创建者可见，其他演示身份无法访问项目内数据 | 中 |
| 访问衔接 | 项目列表、项目切换、资料、任务、数据集与治理列表共同使用可见范围限制 | 中 |
| 项目业务字典 | 可自建字段或复制公共字段，项目间独立保存 | 中 |
| 字段定义 | 名称、唯一编码、类型、必填、单位、枚举及说明 | 中 |
| 数据集填写 | 文本、数值、枚举、日期、布尔对应不同控件，保存时校验类型与必填 | 中 |
| 系统编号 | `dataset_code` 只读展示，实际编号由系统自动生成，自定义字段不得占用 | 低 |
| 后续维护 | 项目卡片提供项目设置；创建者与有管理权限的管理员可维护 | 中 |

复制公共字典会创建项目自己的字段定义，后续修改不反向改动公共字典。修改字典不删除已有数据集元数据；新建、编辑数据集时使用当前字典，详情优先使用项目字段名称。

## 3. 历史兼容与边界

旧项目默认保留全员可见；旧项目没有独立字典时沿用公共的数据集元数据字段。新建项目的字典默认为空，可按需添加，不自动加入此前已移除的作物类型。

本地演示以角色名称代表身份，并初始化一个科研课题组（管理员、加工人员、审核人员）。课题组可见按成员记录计算；个人可见按项目所有者计算。真实人员、组织关系和服务端访问控制未接入。

本轮按此前“不检查”的要求，仅实现代码与表单规则，未运行自动化测试、构建或浏览器功能验证。
