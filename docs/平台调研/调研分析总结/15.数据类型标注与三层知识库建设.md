## Label Studio 参考依据

使用已有本地调研账号登录 `http://127.0.0.1:8080`，读取项目设置和 `/api/templates/`。实际返回 69 个模板、11 个分组，包含 Computer Vision、Natural Language Processing、Audio/Speech Processing、Conversational AI、Chat、Ranking & Scoring、Structured Data Parsing、Time Series Analysis、Videos、Generative AI、Community Contributions。只读取项目和模板，没有修改本地 Label Studio 的项目、标注或任务。精简元数据保存于 [模板分类记录](assets/label-studio-template-categories.json)，不包含账号、密码或会话信息。

官方模板目录同样按使用场景与数据类型组织；模板通过对象标签定义待标注数据、通过控制标签定义标注操作。这支持“先选择数据类型，再选择任务模板”的设计。[官方模板目录](https://labelstud.io/templates/)、[模板组成说明](https://labelstud.io/templates/get_started.html)。

“原始资料层 → 知识编译层 → 知识图谱层”来自本次用户要求，是本项目的知识库建设流程，不是 Label Studio 自带的三阶段功能。

## 数据标注分类

| 数据类型 | 当前提供的标注模板 | 对应处理对象 |
| --- | --- | --- |
| 文本 | 文本分类 | 正文与类别 |
| 图像 | 图片分类、图片框选、图片描述 | 整张图片、区域与描述文本 |
| 问答 | 问答人工复核 | 问题、答案、来源与质量评价 |
| 图文 | 图片问答 | 图片与对应问题答案 |

左侧选择数据类型，右侧展示该类型已有的任务模板。切换类型保留各模板配置，旧的图片导入、框选、标签与问答复核逻辑继续使用。音频、视频、时序和通用结构化数据标注尚未实现，不将这些模板作为可执行功能展示。

知识图谱从普通标注任务卡片中移出，通过“知识库建设”和项目流程中的“知识库”进入，不要求用户手动创建每个知识点或逐条连接关系。

## 三层知识库

| 层次 | 数据与行为 | 前端呈现 |
| --- | --- | --- |
| 原始资料层 | 接入的论文、文档、笔记、图片及优质问答，保留原文件和来源 | 资料目录树、原文或图片预览、原始文件入口 |
| 知识编译层 | 对有可用正文的文档、笔记和优质问答自动创建编译任务，形成带摘要、正文摘录、主题与来源的知识页面 | 知识页面目录、摘要、分节内容、原始资料回溯 |
| 知识图谱层 | 基于当前有效的编译页面聚合抽取实体和关系，合并同名实体，保留知识页面与原始资料关联 | 默认图谱画布、知识页面/知识点/关联数量、搜索、缩放、来源证据与 JSON 导出 |

优质问答限定为数据集成果中已标记“可用”的问答，或来自已通过、已发布版本的有效问答；排除过滤、需修改、不可用和无法判断的条目。未经复核的模拟问答候选不自动作为优质知识来源。图片保留在原始资料目录，本次不提供自动图像知识编译。

知识图谱的全局范围是当前项目、当前数据集的知识库，遵守现有项目和数据集权限，不跨项目暴露资料。当前代码没有独立的旧“全局索引”页，本次新增“知识图谱 · 全局索引”视图，并使 `#global-index` 指向知识库图谱展示。

## 自动建设与来源衔接

1. 语料接入后，文档沿用默认自动解析；纯文本可直接进入知识编译。
2. 登录身份具有编辑权限时，监听当前可用资料和优质问答，自动创建知识编译任务；无需进入知识库页面逐条启动。
3. 当前可编译资料全部形成有效知识页面后，自动创建聚合图谱任务。
4. 原文修订、资料改名、优质问答变化或知识页面变化后重新建设对应结果；同一输入签名的执行中任务与有效成果复用。
5. 旧任务完成时如果资料已变化，记录为过期失败，避免旧结果替换当前内容；删除原始资料后，不将旧编译页面继续纳入当前图谱。
6. 任务和结果保存在项目内，编译与自动建图使用中间成果，不自动增加正式数据集版本或跳转共享平台。已有历史成果保留。

图谱来源片段同时记录原始资料、编译页面和记录位置。知识库默认同时显示目录树与图谱；查看原始资料或编译页面时，可以继续通过阶段卡片切换。图谱的实体关系表保留在成果校订界面，知识库全局索引以画布为主。
