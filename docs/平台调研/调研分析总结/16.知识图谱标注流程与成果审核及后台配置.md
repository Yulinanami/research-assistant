## 知识图谱作为标注流程

数据标注仍按文本、图像、问答、图文分类。文本类型中提供“知识图谱”流程，内部包含原始资料、知识编译、图谱抽取与来源校订；目录树、知识页面、图谱和来源证据继续保留，不再有独立知识库路由或项目流程步骤。旧 `#knowledge` 与 `#global-index` 地址兼容进入数据标注的知识图谱流程。

流程参考 LightRAG 的正文切片、实体关系抽取、合并与来源组织方式；官方提示词分别定义实体信息和关系两端、关系说明等要求，本项目据此配置实体抽取、关系抽取及合并提示词。[LightRAG 项目](https://github.com/HKUDS/LightRAG)、[官方提示词代码](https://github.com/HKUDS/LightRAG/blob/main/lightrag/prompt.py)。这些是流程与字段参考，不表示本 Demo 已连接 LightRAG 服务，也不将自定义提示词宣称为 LightRAG 原生格式。

接入后的自动解析、知识编译和聚合图谱仍使用任务中心记录。图谱支持一键保存来源校订，以及按需查看、编辑实体和关系明细；保存校订后作为标注成果提交审核。用户无需从零逐点构建图谱。

## 标注成果审核

数据标注页增加“标注流程 / 成果审核”两个页签。审核覆盖文本分类、图片分类、区域框选、问答标注、图片描述、图片问答及知识图谱。分类、框选和问答标注的提交操作进入本页成果审核，不自动跳转数据治理与共享。

| 状态 | 操作与条件 |
| --- | --- |
| 待提交 | 编辑成员完成标注，校验内容与模板后提交 |
| 待审核 | 审核成员查看提交快照、图片区域、标签、问答、图谱及来源，填写审核意见 |
| 已通过 | 记录审核人、时间与意见，写入审核历史和任务记录 |
| 已退回 | 退回意见必填，编辑成员修改后重新提交 |

提交时冻结成果内容、模板签名和当时的审核标准。审核前再次比对内容签名；成果变更后，原审批不继续生效，状态显示待提交并要求重新提交。审核操作遵守现有编辑、审核权限，退回和重新提交均保留历史。

图谱提交前要求保存来源校订；分类要求完成标签选择；框选要求有效区域和类别；问答标注要求有效答案与质量标记；图片描述和图片问答保留原图。人工审核不以模型预测替代。

标注成果审核与正式治理审核分开记录。标注数据集需要通过本页成果审核，才可从项目成果另行提交正式治理审核；中间成果仍保持项目内加工结果。新人工问答标注在通过成果审核后，才作为优质问答进入自动图谱流程；已通过或已发布的历史问答继续按原有效状态使用。

## 集中后台配置

右上角入口与设置页统一为“后台配置”。解析参数、模型使用与评测、受众模板、标签模板、清洗与任务默认值、导出格式继续集中维护，并新增以下提示词配置：

| 分类 | 配置项 |
| --- | --- |
| 解析 | 文档解析提示词 |
| 问答 | QA 生成、SFT 问答增强 |
| 知识图谱 | 知识编译、实体抽取、关系抽取、实体与关系合并 |
| 图文 | 图片描述、图片问答 |
| 审核 | 问答辅助标注、标注成果审核标准 |

可按分类筛选，逐项恢复默认。解析任务、预处理 QA 任务、项目预设流程、图文任务和自动图谱任务读取集中配置，并在创建时保存实际提示词快照。受众和表达模板仍按任务选择，提示词中的受众字段在创建任务时填入；已经修改的任务草稿不会被后台默认值静默覆盖。

已启动任务和历史任务保留原配置，后台修改用于后续新任务。图谱流程提供“重新生成”，按当前后台配置重新编译，全部当前编译任务完成后再聚合图谱，保留历史成果。审核标准也在提交时冻结，避免审核途中修改标准后含义不一致。配置和账号仍沿用浏览器本地演示保存，不在前端引入生产模型密钥。
