# 平台命令与配置

## 1. Data-Juicer

### 1.1 启动 Web 界面

```powershell
cd D:\myprojects\调研的开源项目\data-juicer

.\.venv\Scripts\python.exe -X utf8 -m streamlit run app.py --server.address 127.0.0.1
```

### 1.2 清理问答中的思维链

```powershell
cd D:\myprojects\调研的开源项目\data-juicer

$sourceFile = (Read-Host "数据文件路径").Trim().Trim('"').Replace('\', '/')

.\.venv\Scripts\python.exe -X utf8 tools/process_data.py --config demos/remove-think.yaml --dataset "{configs: [{type: local, path: '$sourceFile'}]}"
```

```yaml
project_name: remove-think
dataset_path: ''
# 输入文件由运行时的 --dataset 参数指定。
text_keys: output
np: 1
work_dir: './outputs/remove-think/{job_id}'
export_path: '{work_dir}/processed.jsonl'
process:
  - replace_content_mapper:
      pattern: '^\s*<think>.*?</think>\s*'
      repl: ''
```

## 3. Docling

### 3.1 使用 GPU 转换论文 PDF

```powershell
cd D:\myprojects\docling

.\.venv\Scripts\docling.exe "C:\Users\asus\Downloads\Attention_is_all_you_need.pdf" --pipeline standard --pdf-backend pypdfium2 --device cuda --to md --to html --to json --image-export-mode referenced --output "./outputs/attention-standard-pdfium"
```

### 3.2 启动 Web 界面

```powershell
cd D:\myprojects\docling

$env:PYTHONUTF8 = "1"
$env:DOCLING_DEVICE = "cuda"
$env:DOCLING_SERVE_ENG_LOC_NUM_WORKERS = "1"
$env:DOCLING_SERVE_LOAD_MODELS_AT_BOOT = "false"

.\.venv\Scripts\docling-serve.exe run --enable-ui --host 127.0.0.1 --port 5001
```

### 3.3 同一内容的不同格式转换

```powershell
cd D:\myprojects\docling

.\.venv\Scripts\docling.exe ".\inputs\format-demo" --from pdf --from docx --from html --pipeline standard --device cuda --to md --to json --to chunks --chunks-type hierarchical --output ".\outputs\format-demo"
```

## 4. Label Studio

### 4.1 启动 Web 界面

```powershell
cd D:\myprojects\label-studio

$env:PYTHONUTF8 = "1"

.\.venv\Scripts\label-studio.exe start --port 8080 --data-dir 'D:\myprojects\label-studio\data'
```

### 4.2 文本实体标注配置

```xml
<View>
  <Labels name="entity" toName="text">
    <Label value="采样时间" background="#FFD591"/>
    <Label value="采样深度" background="#91CAFF"/>
    <Label value="土壤含水量" background="#B7EB8F"/>
  </Labels>
  <Text name="text" value="$text" granularity="symbol"/>
</View>
```
