**调研 OpenMetadata、DataVines、Dataverse，再用 DataHub 和 CKAN 做对比。** 这五个项目分别覆盖元数据管理、质量检查和数据共享，调研重点比较清楚。

## 1. 推荐的平台

| 项目                                                         | 主要功能                                                   | 对应您的需求                                           | 建议重点体验                                                 |
| ------------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| [**OpenMetadata**](https://github.com/open-metadata/OpenMetadata) | 数据目录、元数据、业务术语、分类标签、质量检查、角色与策略 | **数据字典、元数据规范、目录服务、质量管理**           | 接入一个数据库，查看表和字段；补充字段含义、标签和负责人；配置质量检查，查看结果 |
| [**DataVines**](https://github.com/datavane/datavines)       | 数据质量规则、自定义 SQL 检查、定时检查、错误数据和报告    | **质量要求定义、标准化清洗中的质量评估、质检结果展示** | 用一张含空值、重复值、非法取值的样例表，配置规则并查看问题记录 |
| [**Dataverse**](https://github.com/IQSS/dataverse)           | 科研数据集管理、元数据、版本、审核发布、受限文件与访问申请 | **数据集详情、申请使用、审批下载、版本发布**           | 上传科研数据，保存草稿、提交审核、发布新版本；用另一个账号申请受限文件 |

| [**CKAN**](https://github.com/ckan/ckan)                     | 数据门户、数据集目录、文件发布、组织管理、检索和数据 API   | **数据集成果展示、数据预览、目录服务、API 服务**       | 发布一个数据集，填写介绍和标签，配置表格数据预览，通过 API 查询数据 |

## 2. 为什么先看这三个

### OpenMetadata：看数据如何统一管理

重点回答：**数据在哪里、字段是什么意思、谁负责、质量怎么样。**

它适合作为综合治理平台的第一站。术语表、字段说明和分类标签，可以用于研究您需求里的数据字典与元数据规范；具体的数据编码和取值规则，仍需逐项验证。

### DataVines：看质量规则如何落地

重点回答：**如何配置检查、找到错误记录、查看检查报告。**

它主要面向数据库表和字段检查，支持自定义 SQL 和定时任务。对论文问答的事实正确性、回答是否符合原文，仍需要模型评价或人工审核，不能仅靠这些规则完成。[官方功能说明](https://github.com/datavane/datavines#features)

### Dataverse：看成果如何审核、发布和授权使用

重点回答：**数据加工完成后，如何成为可管理、可申请使用的数据集。**

它有科研数据场景，支持版本、审核发布和受限文件访问申请，比较贴近您需求中的成果管理。申请表是否能直接满足“申请人、部门、申请理由”，需要实际体验确认。[官方管理文档](https://guides.dataverse.org/en/latest/user/dataset-management.html)

## 3. 调研时要注意的边界

- **目录中的权限管理与原始数据下载权限要分别验证**，不能看到角色配置就认定满足审批下载。
- **元数据版本与数据内容版本要分别验证**，您需要的是问答提取、增强后产生新的数据集版本。
- **DataHub 要以开源版为准**，官方同时提供 Cloud 产品，不能把云端能力直接记入开源版报告。[官方版本说明](https://github.com/datahub-project/datahub#pick-your-path)

**推荐顺序：OpenMetadata → DataVines → Dataverse → DataHub → CKAN。** 前三个先完成实际体验，后两个用于比较设计和功能覆盖
